START HERE
==========

This folder is everything you need. Delete any other RecipeGenie files
you downloaded before this — they were earlier drafts and are now
out of date. This package is the current, correct version.

HOW TO RUN IT (two terminals, both stay open)

Terminal 1 — backend:
  cd backend
  python3 -m venv venv
  source venv/bin/activate          (Windows: venv\Scripts\activate)
  pip install -r requirements.txt
  cp .env.example .env              (Windows: copy .env.example .env)

  Now get a free API key at https://aistudio.google.com (no credit
  card required). Open .env in a text editor and paste it after
  GOOGLE_API_KEY=  then save it.

  uvicorn app.main:app --reload

Terminal 2 — frontend (open a NEW terminal window, from the folder
that contains this file, NOT the backend folder):
  python3 -m http.server 5500

THEN OPEN IN YOUR BROWSER:
  http://localhost:5500/index.html

Do not double-click index.html directly — it must be opened through
the http://localhost:5500 address above, or the site won't be able to
talk to the backend.
